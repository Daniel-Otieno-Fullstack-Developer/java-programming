# Java Methods

Eight beginner tasks on writing your own Java methods: `void` methods, parameters, return values, `boolean` methods, overloading and pass by value.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [Task1.java](Task1.java) | Welcome Banner | `void` method | A `void` method written once and called twice |
| [Task2.java](Task2.java) | Matatu Tickets | parameters | One method with three parameters prints any ticket |
| [Task3.java](Task3.java) | Circle Calculator | `return` `double` | Methods return the area and circumference; another rounds them |
| [Task4.java](Task4.java) | Grade Method | `return` `char` | A `char` method grades every mark read in a loop |
| [Task5.java](Task5.java) | Leap Year Checker | `boolean` method | A `boolean` method used by another method |
| [Task6.java](Task6.java) | Overloaded Totals | overloading | Three methods share one name with different parameters |
| [Task7.java](Task7.java) | Pass by Value | pass by value | Compares an `int` parameter, a returned value and an array |
| [Task8.java](Task8.java) | Mini Calculator | methods working together | A `switch` calls one of four small methods |
