# Java Loops

Eight beginner tasks on repeating code in Java with `for`, `while` and `do while`, the enhanced `for` loop, `break`, `continue` and nested loops.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [Task1.java](Task1.java) | Fuel Price Table | `for` with a step | Counts from 5 to 30 in steps of 5 with a `for` loop |
| [Task2.java](Task2.java) | Chama Savings | `for` with a running total | Keeps a running total across the months |
| [Task3.java](Task3.java) | Class Average | `while` with a sentinel | Totals marks until a -1 sentinel |
| [Task4.java](Task4.java) | PIN Attempts | `do` `while` | Up to three PIN attempts with `do while` |
| [Task5.java](Task5.java) | Skip the Absentees | `continue` | Uses `continue` to leave absent students out |
| [Task6.java](Task6.java) | Guess the Number | `while` (true) and `break` | Hints until the right guess, then `break` |
| [Task7.java](Task7.java) | Seating Plan | nested `for` | Nested loops print lettered rows of numbered seats |
| [Task8.java](Task8.java) | Vowel Counter | enhanced `for` | Visits each character with an enhanced `for` |
