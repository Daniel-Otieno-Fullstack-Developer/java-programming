# Java Programming

Java exercises and worked solutions from the ICT courses I teach at Delhi College, Eastleigh, Nairobi.

The course runs from the first data types through to classes, inheritance, exceptions and collections. Each topic folder has eight tasks, each with a tested solution written for Java 17 or later, with no packages and no external libraries.

## Contents

| # | Topic | What it covers | Level |
|---|---|---|---|
| 1 | [Data Types and Variables](Data%20Types%20and%20Variables) | Primitive types, `String`, `Scanner` input, `var`, `final` constants | Beginner |
| 2 | [Operators and Expressions](Operators%20and%20Expressions) | Arithmetic, integer division and `%`, casting, compound assignment, logical operators | Beginner |
| 3 | [Decisions](Decisions) | `if`, `else if`, `else`, nested decisions, `switch` statements and switch expressions | Beginner |
| 4 | [Loops](Loops) | `for`, `while`, `do while`, enhanced `for`, `break` and `continue`, nested loops | Beginner |
| 5 | [Methods](Methods) | Parameters, return values, `static` methods, overloading, pass by value | Beginner |
| 6 | [Arrays](Arrays) | 1D and 2D arrays, searching, bubble sort, the `Arrays` class | Beginner |
| 7 | [Strings](Strings) | `String` methods, `equals` vs `==`, `StringBuilder`, `printf` formatting | Beginner |
| 8 | [Classes and Objects](Classes%20and%20Objects) | Fields, constructors, `this`, getters and setters, encapsulation, static vs instance | Intermediate |
| 9 | [Inheritance and Polymorphism](Inheritance%20and%20Polymorphism) | `extends`, `super`, overriding, abstract classes, interfaces | Intermediate |
| 10 | [Exceptions](Exceptions) | `try`/`catch`/`finally`, checked vs unchecked, `throw`, custom exceptions | Intermediate |
| 11 | [ArrayList and Collections](ArrayList%20and%20Collections) | `ArrayList`, `HashMap`, looping over collections | Intermediate |

## In each folder

- **README** — what each task does, with sample output.
- **Task1.java … Task8.java** — a worked solution for each task. Each file holds a `public class` with the same name; from Classes and Objects onwards, the classes a task uses sit in the same file.

## Compiling and running

```bash
javac Task1.java
java Task1
```
